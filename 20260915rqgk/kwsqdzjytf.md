# 卵泡内膜细胞和颗粒细胞瘤

> 更新时间：2026-09-15 (UTC+8)

卵泡是卵巢的组织结构成分之一，卵泡每个月都会有一颗成熟以后排出卵子，卵子与精子结合，就会形成受精卵发育成胚胎，很多人在备孕的时候都会到医院进行卵泡的检查，那么卵泡内膜细胞和颗粒细胞瘤是怎么形成的呢?
卵泡内膜细胞和颗粒细胞瘤
　　卵泡膜细胞瘤：为有内分泌功能的卵巢实性肿瘤，因能分泌雌激素，故有女性化作用。常与颗粒细胞瘤合并存在(以颗粒细胞瘤成分为主者称颗粒-卵泡膜细胞瘤，以卵泡膜细胞瘤成分为主者称卵泡膜-颗粒细胞瘤)，但也有纯卵泡膜细胞瘤。为良性肿瘤，多为单侧，大小不一。圆形或卵圆形，也有分叶状。表面被覆有光泽、薄的纤维包膜。切面实性，灰白色。镜下见瘤细胞短梭形，胞浆富含脂质，细胞交错排列呈旋涡状。瘤细胞团为结蒂组织分隔。常合并子宫内膜过生长，甚至子宫内膜癌。恶性卵泡膜细胞瘤较少见，可直接浸润临近组织，并发生远处转移。其预后较一般卵巢癌为佳。

　　一，CT检查　CT检查是十分常用的诊断肿瘤的方式，通过CT，能够较为准确的判断肿瘤的体积，位置以及形状等，肿瘤多半靠近子宫肌层，如果肿瘤的体积较大，我们还能够看到散落在小片状低密度区域，不过肿瘤内很少出现钙化。通过增强CT扫描后，患者主要会表现为缓慢渐进性轻度强化。

　　二，MRI检查　MRI是对于肿瘤诊断十分重要的方式，特别是确定肿瘤的性质，分期有着非常重要的意义。T1WI和T2WI出现普遍的低信号，T2WI则出现夹有结节状、絮状则为高信号。所有的肿瘤都没有出现“漩涡征”和“假包膜征”,盆腔内部以及腹股沟区发生转移者，会出现肿大淋巴结。

　　卵泡膜细胞瘤(thecoma)为良性功能性肿瘤，因为肿瘤细胞可产生雌激素，绝大多数患者有雌激素增多产生的体征，通常表现为月经不调和乳腺增大，多发生于绝经后的妇女。卵泡膜细胞瘤呈实体状，由于细胞含有脂质，切面色黄。镜下，瘤细胞由成束的短梭形细胞组成，核卵圆形，胞浆由于含脂质而呈空泡状。玻璃样变的胶原纤维可将瘤细胞分割成巢状。瘤细胞黄素化时，细胞大而圆，核圆居中，与黄体细胞相象，称为黄素化的卵泡膜细胞瘤。
不孕不育要做哪些检查
　　不孕不育是夫妻双方的事情，要做的检查非常多，一般建议如果一对夫妻不孕，先给男方做检查，因为男方检查相对比较少，需要做精液常规检查、精子畸形率筛查，还有一个就是免疫因素，做免疫抗体的测定，看看是否有抗精子抗体阳性。如果男方的精液活力、畸形率都是正常的，主要问题可能在女方身上。女方的因素比较多，要查阴道炎症、宫颈有没有重度炎症，子宫的问题主要看子宫有没有炎症，子宫内膜的厚度适不适合怀孕。其中最重要的影响女方不孕的两个因素，一个是排卵因素，一个是输卵管因素。如果有盆腔炎症，输卵管很可能不通或者通而不畅。还要看月经是否规律，如果月经不规律，多半可能会有排卵障碍。同时，以现在的科学手段，有10%-20%左右的不孕原因目前还未知，因为现在科学手段查不到，这叫不明原因性不孕，可能和心理、情绪，还有一些不知道的因素有关系。

　　男方检查：

　　1. 精液常规检查：怀孕需要男方提供精子，首先需要对男性的精液进行全方位检查，比如精子的数目、质量、活性、形态等。

　　2. 内分泌检查：男性的性功能受内分泌影响，倘若内分泌系统出现紊乱，会影响男性正常排精。内分泌检查主要测激素T、LH、FSH等，以及激发试验HCG。

　　3. 疾病检查：倘若男性患有前列腺炎、睾丸炎、精索静脉曲张等疾病，需要及时进行治疗，同时检查家族遗传病史，排除遗传因素。

　　4. 精浆生化检查：通过该检查，能够了解附睾、前列腺、精囊腺的功能，主要针对少精、无精、精子活力低的患者。

　　5. 染色体检查：染色体可是遗传物质的载体，要是染色体出现数目或结构异常，会严重影响精子的生成，从而导致不孕不育，所以也需要进行排查。

　　女方检查：

　　1. 全身检查：首先，医生需要了解女方的所有信息，包括年龄、月经史、手术史、疾病史、家族疾病遗传史、不良嗜好等，同时进行全身检查以及妇科检查，对女性的阴道、子宫、卵巢等生殖器官有个大致了解。

　　2. 性激素六项检查：该检查主要确诊女性是否存在内分泌失调现象，主要检查黄体生成激素、孕酮、雌二醇、卵泡生成素、催乳素、睾酮这六项性激素。

　　3. B超监测排卵：怀孕离不开精子也离不开卵子，卵巢是分泌卵子的场所，所以需要对卵巢的基本情况以及储备功能有所了解，除了评估卵巢的功能，还要对子宫的大小、内膜的厚度、卵泡的个数以及直径进行测量。

　　4. 输卵管检查：输卵管一来摄取卵子输送精子，二来负责将受精卵送回子宫，身上承担着生育重任，只有输卵管保持畅通，怀孕才大有可能。一般的方法就是采用输卵管造影术，在了解输卵管是否堵塞的基础上，查看宫腔是否发生病变。

　　5. 宫腹腔镜检查：必要的话，需要对患者进行宫腔镜检查或腹腔镜检查，有利于检测输卵管的畅通程度，以及直接排除宫腔异常等病症，为后续的治疗提供依据。

　　6. 其他检查：染色体、免疫学、病毒等检查也不能少。
